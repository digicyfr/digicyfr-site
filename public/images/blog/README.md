# Blog Post Images

This directory contains images for blog posts. Below are the required images for current blog posts.

## Image Requirements

### General Specifications
- **Format**: JPG or WebP (WebP preferred for performance)
- **Dimensions**: 1200x630px (OpenGraph standard for social sharing)
- **Aspect Ratio**: 16:9 recommended
- **File Size**: < 200KB (optimized for web)
- **Quality**: High resolution, professional photography or illustrations

### Custom Photography
If creating custom images:
- Use natural lighting
- Keep backgrounds clean and uncluttered
- Focus on hands-on-device shots for authenticity
- Include your branding subtly if appropriate
- Ensure diversity in representation

## Optimization

After obtaining images, optimize them:

```bash
# Using ImageMagick (if installed)
magick convert input.jpg -resize 1200x630^ -quality 85 output.jpg

# Using online tools
- TinyPNG (https://tinypng.com)
- Squoosh (https://squoosh.app)
- ImageOptim (Mac)
```
