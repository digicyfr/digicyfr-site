A universal spacing, typography & layout system for the Digicyfr Blog

📘 Purpose

This document defines the global spacing, typography, and layout rules for all blog-related pages and components.
It ensures a consistent, readable, and premium-quality experience across:

Blog Listing (/blog)

Blog Post (/blog/[slug])

Category pages

Tag pages

Filters, search, related posts

All blog components (cards, hero, categories, tags, share)

🎯 Global Spacing Scale (Use ONLY These Values)
4 — 8 — 16 — 24 — 32 — 40 — 48 — 56 — 64 — 80 — 120px


No custom/random spacing values allowed.

✏️ Typography Rules
Headings

H1: 40–48px, bold, line-height 1.2

H2: 28–32px, semibold, line-height 1.3

H3: 20–24px, semibold, line-height 1.35–1.4

H4: 18px, medium

Body Text

Font size: 16–18px

Line-height: 1.5–1.65

Max text width: 70–80 characters (65ch recommended)

Paragraph Spacing

Paragraph → next paragraph: 16–20px

Lists

List item spacing: 12–16px

Bullet number/icon → text: 8px

🧩 Vertical Rhythm Rules

These rules apply across all blog pages:

1. More space above headings than below

Space ABOVE section titles: 32–48px

Space BELOW section titles: 16–24px

2. All major sections must have breathing room

Section top padding: 48–64px

Section bottom padding: 48–64px

3. Content width rules

Max-width for content: 720–800px

For lists & diagrams: max width: 900px

4. Cards must have equal padding

Internal padding: 24–32px

5. No two different background colors can visually touch

Always keep at least 48px padding before color shift.

🧱 Component-Level Spacing Rules

This section defines spacing for every major component in the blog.

🟦 1. BlogHero (Blog Landing Page Hero)
Spacing:

Top padding: 96px

Title → description: 16–24px

Description → search bar: 24–32px

Search bar → category shortcuts: 24–40px

Bottom spacing before next section: 48–64px

🟩 2. BlogList (Listing Grid)
Grid:

Grid gap (desktop): 32px

Grid gap (tablet): 24px

Row gap (mobile): 24–32px

Layout around grid:

Section title → filters: 24–32px

Filters → grid: 24–32px

Grid → pagination or next section: 48–64px

🟧 3. BlogCard (Preview Cards)
Internal padding:

24–32px uniform

Internal spacing:

Image → category badge: 16px

Category → title: 12–16px

Title → excerpt: 12–16px

Excerpt → meta row: 16–24px

Meta row items gap: 12px

External spacing:

Between cards in grid: handled by grid (use 32px)

🟨 4. BlogCategories (Category Filters)
Spacing:

Header → category list: 24–32px

Category item → next item: 12–16px

Category list → blog list/grid: 32–48px

🟫 5. BlogSearch
Spacing:

Search input internal padding: 12–16px

Search → filters/categories: 20–32px

Search → grid: 32px

🟪 6. BlogPost (Single Post Page)
Layout:

Top padding: 64–80px

Content max width: 720–800px

Bottom spacing before related posts: 64px

Hero section:

Category badge → title: 16px

Title → meta info: 16–24px

Meta info → hero image: 24–32px

Hero image → content: 32–40px

Content spacing:

H2 spacing:

Above: 40px

Below: 16px

H3 spacing:

Above: 32px

Below: 12px

Paragraph → paragraph: 16–20px

Paragraph → list: 16px

List → next section: 16–24px

Blockquote vertical padding: 24px

Blockquote → next element: 24–32px

Code block vertical spacing: 24–32px

🟩 7. RelatedPosts Section
Spacing:

Section title → cards: 24–32px

Cards grid gap: 32px

Section → next section: 48–64px

🟥 8. ShareButtons
Spacing:

Section top margin: 32–40px

Buttons gap: 12–16px

Section bottom spacing: 32–48px

🟦 9. Tags (Inside BlogPost)
Spacing:

Tags section top: 32px

Tag → next tag: 8–12px

Tag internal padding: 8–12px

Tag section bottom: 32px

🟧 10. Pagination (If implemented)
Spacing:

Pagination container top: 40–48px

Page numbers gap: 12–16px

🌍 Spacing Rules for Mobile (Important)
Reduce all vertical spacing values by 20–30%:

Examples:

64px → 48px

48px → 32px

32px → 24px

24px → 16px

16px → 12px

Grid becomes single-column:

Row gap: 24–32px

Title sizes scale down:

H1: 28–32px

H2: 22–26px

H3: 18–20px

🧭 Consistency Check Before Finalizing a Page
Spacing Checklist

 All section spacing uses 48–64px

 All components use global spacing scale

 No random margins/padding

 Vertical rhythm consistent across page

Typography Checklist

 Headings follow H1 > H2 > H3 sizing

 Max width 70–80ch enforced

 Line height 1.5–1.65 for paragraphs

Layout Checklist

 Cards have equal padding (24–32px)

 Grid gaps consistent (24–32px)

 No background sections touching
